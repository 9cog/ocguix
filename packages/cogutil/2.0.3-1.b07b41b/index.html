Low-level C++ prog utilities used by OC components

The OpenCog utilities is a miscellaneous collection of C++ utilities used for typical programming tasks in multiple OpenCog projects.

Installation

Install cogutil 2.0.3-1.b07b41b as follows:

guix install cogutil
