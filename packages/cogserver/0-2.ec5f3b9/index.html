cogserver

0-2.ec5f3b9

OC network server

Website: https://github.com/opencog/cogserver/
License: AGPL 3
Build system: cmake-build-system
Dependencies: atomspace boost cogutil gmp guile

Description

The OpenCog Cogserver is a network and job server for the OpenCog framework.

Installation

Install cogserver 0-2.ec5f3b9 as follows:

guix install cogserver@0-2.ec5f3b9

Or install the latest version:

guix install cogserver
