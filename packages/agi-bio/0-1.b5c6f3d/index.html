agi-bio

0-1.b5c6f3d

Genomic and proteomic data & pattern mining

Website: https://github.com/opencog/agi-bio/
License: AGPL 3
Build system: cmake-build-system
Dependencies: atomspace cogutil gmp guile

Description

This is a package for genomic and proteomic research using the OpenCog toolset with Guile. This includes experiments in applying pattern mining and other OpenCog components.

Installation

Install agi-bio 0-1.b5c6f3d as follows:

guix install agi-bio@0-1.b5c6f3d

Or install the latest version:

guix install agi-bio
