attention

0-1.87d4367

OC attention allocation subsystem

Website: https://github.com/opencog/attention/
License: AGPL 3
Build system: cmake-build-system
Dependencies: atomspace boost cogserver cogutil gmp guile

Description

Attention Allocation is an OpenCog subsystem meant to control the application of processing and memory resources to specific tasks.

Installation

Install attention 0-1.87d4367 as follows:

guix install attention@0-1.87d4367

Or install the latest version:

guix install attention
